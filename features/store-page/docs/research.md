# Research — Store Page

**Last Updated:** 2026-06-22

---

## 1. Competitive Analysis

| Platform | How they show cashback | Coupon approach |
|----------|----------------------|-----------------|
| CashKaro (current) | Small text, below fold | Flat list, no ranking |
| Cashrewards (AU) | Large hero, above fold | Top 3 highlighted, rest collapsed |
| TopCashback (UK) | Rate in header, always visible | Categorised by type |
| Honey (browser ext) | Auto-applied, no explicit display | Auto-tested, best shown first |
| GoPaisa | Similar to current CashKaro | Flat list |

**Key insight:** Every high-performing cashback platform puts the rate in the hero. CashKaro is the outlier burying it.

---

## 2. User Research Findings

### Session Recording Analysis (Hotjar — 500 sessions)

| Observation | % of sessions |
|-------------|--------------|
| Users scroll past cashback rate without pausing | 67% |
| Users click a coupon before reading cashback rate | 43% |
| Users leave without clicking Shop Now | 58% |
| Users try more than 2 coupons before giving up | 31% |

### User Interview Insights (n=8)

| Insight | Representative quote |
|---------|---------------------|
| Users don't trust coupon freshness | "I never know if the code actually works until I try it" |
| Cashback rate drives decision more than coupons | "I came for the cashback, coupons are a bonus" |
| Page feels slow | "By the time it loads I've already Googled the coupon code elsewhere" |

## 3. Internal Data

| Metric | Value |
|--------|-------|
| Avg store page load time (4G) | 4.8 seconds |
| Bounce rate | 58% |
| Shop Now CTR | 22% |
| Top stores by page views | Amazon, Flipkart, Myntra, Ajio, Nykaa |
| % of cashback transactions from store page | 71% |

---

## 4. Key Insights

1. The cashback rate is the primary value proposition — it needs to be unmissable
2. Coupon trust is broken — users want verified + recently-tested badges
3. Speed is a conversion killer — 4.8s load time is causing direct competitor leakage
4. 71% of all cashback transactions start on the store page — this is the most impactful page to optimise
