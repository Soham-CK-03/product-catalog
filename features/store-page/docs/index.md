## What is Store Page?

The Store Page is the core discovery surface in CashKaro. It is the page a user lands on when they click any brand or merchant — Amazon, Flipkart, Myntra, etc. It shows the cashback rate, all active coupons, top deals, and a direct link to shop.

This is one of the highest-traffic pages on the platform. Every cashback transaction starts here.

---

## Feature Summary

| | |
|--|--|
| **Problem** | The current store page is cluttered, loads slowly, and buries the cashback rate — the single most important piece of information for the user. |
| **Solution** | A redesigned store page that leads with cashback rate, surfaces the best coupons above the fold, and loads under 2 seconds. |
| **Who is it for** | All CashKaro users browsing for cashback deals |
| **Business goal** | Increase click-through to store (Shop Now CTA), reduce bounce rate, improve cashback transaction volume |
